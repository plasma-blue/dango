# 团子画板隐私声明 (Privacy Policy)

**生效日期**：2026年9月1日  
**最近更新**：2026年9月9日  

团子画板（Dango，以下简称“我们”或“本工具”）由个人开发者开源维护。我们始终恪守**本地优先、零隐性收集**与**数据绝对归属用户**的纯粹产品哲学。

本隐私声明旨在客观、详尽地向您说明本工具的数据运行架构：我们如何处理数据，以及为什么您在使用团子画板时享有极高水准的隐私与安全保障。

---

### 一、核心架构：纯客户端运行与零服务器存储

1. **无账户体系、零个人身份信息收集**
   - 团子画板不需要注册，也没有账号系统。我们不收集、不要求、亦无法获取您的姓名、电子邮件地址、电话号码、设备唯一标识符等任何个人身份识别信息。

2. **本地优先与无后端数据库**
   - 团子画板是一款纯客户端运行的单页应用。
   - 您在画板中创建、键入、绘制或组织的**所有节点文字、连线拓扑、思维草稿、编组结构及个性化设置**，均仅保存在您当前设备浏览器的本地存储空间中，或由您手动导出为 `.dango` 本地离线文件。
   - **我们没有设立任何用于接收、暂存、解析或持久化用户画板内容的后端服务器与数据库**。您的构想与灵感从未离开过您的设备。

---

### 二、网络基础设施与第三方服务

1. **Cloudflare 基础设施与基础网络访问日志**
   - 官方在线站点（如 `dango.ink` 及 `blog.dango.ink`）托管部署于 Cloudflare 平台（Cloudflare Pages / CDN）。
   - 当您的浏览器访问本站下载静态应用资源（HTML、JavaScript、CSS、图标等）时，Cloudflare 作为全球网络基础设施服务商，出于防御网络攻击（如 DDoS 防范）、流量调度、故障排查及保障基础网络安全之合规需要，可能会自动记录标准的 HTTP/HTTPS 网络请求日志。
   - 此类基础日志通常包括：访问者的公网 IP 地址、浏览器 User-Agent、请求 URL、Referer 来源页面以及访问时间戳。
   - 此类日志由 Cloudflare 依据其自身的[《Cloudflare 隐私政策》](https://www.cloudflare.com/privacypolicy/)进行管理与保护。**开发者既不会亦无法将此类底层网络访问日志与您在本地画板上绘制的任何具体图表或文本内容相关联**。

2. **第三方外部网络资源（外链图片与字体）**
   - **外链图片与壁纸**：如果您主动在画板中引用了外部 HTTP/HTTPS 图片 URL（如图片节点或背景底图），您的浏览器将直接向该第三方图片服务器发起请求，该过程遵循该第三方服务商的数据与隐私条款。
   - **网络字体按需加载**：本应用默认优先调用操作系统本地已有的系统手写字体（如 Windows 上的 `Segoe Print`，macOS 上的 `Chalkboard SE`）。在开启特定手写模式时，中文字体（霞鹜文楷）将通过 Google Fonts 提供的公开 CDN 进行按需异步下载。
   - **完全断网离线支持**：如果您身处对网络隔离有严苛要求的保密环境，您可以直接使用我们的单文件离线发布包（`dango.html`）或自建 Docker 容器，在完全切断互联网连接的状态下 100% 离线使用。

### 三、数据分享与链接生成的运行原理

团子画板提供了便捷的“生成分享链接（LINK / EMBED）”功能：
- 该功能基于 `LZString` 纯客户端算法，将您画板上的数据压缩并完整编码写入 URL 的锚点哈希值（Hash，即 `#` 之后的部分）。
- 根据国际互联网 W3C 标准与 HTTP 协议规范，**URL 中 `#` 及其后续内容严格仅在用户本地浏览器内部解析，绝不会作为 HTTP 请求的一部分发送给任何 Web 服务器**。
- 只有被您显式分享并获得完整 URL（含 Hash）的人，其本地浏览器才能利用内置的解压算法将数据还原渲染。在此过程中，没有任何服务端数据沉淀。

---

### 四、零广告、零商业追踪与零 Cookie

- **无广告集成**：我们不展示任何第三方商业广告。
- **无追踪探针**：我们不在代码中埋设任何商业用户画像追踪 SDK、行为分析探针（如 Google Analytics、百度统计）或社交媒体跟踪像素（如 Meta Pixel）。
- **无追踪 Cookie**：本工具不向您的浏览器植入任何用于追踪或营销目的的持久性 HTTP Cookie。

---

### 五、您对数据的绝对控制权（删除与清除）

您对存储在本地设备上的所有画板数据拥有绝对的控制权：
- **主动销毁**：您可以通过点击界面上的“清空”按钮（回收站图标）即时抹去本地数据；或随时通过浏览器的“清除网站数据 / 清理缓存”功能，一键彻底销毁 `localStorage` 中的全部画板记录。
- **隐私浏览**：若您在浏览器的“无痕模式 / 隐私窗口（Incognito / Private Browsing）”中使用本工具，所有数据将在您关闭窗口的瞬间由浏览器底层自动物理销毁。
